# Decisions

One file per decision: `docs/decisions/YYYY-MM-DD-short-slug.md`. Two agents deciding on the same day never edit the same line.

```
---
date: 2026-10-28
by: Ashu
request: 238
---
**The decision in one sentence.** The reason, and what it changes.
```

`request` is the GitHub issue number of the request it belongs to (optional). Decisions up to 2026-10-28 are in `docs/DECISIONS.md` (an archive; do not add to it).
