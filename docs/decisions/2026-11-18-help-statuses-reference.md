**The status lists and their use-cases go into the Help Reference section as one page, `/help/statuses`** ("Phases and statuses: the lists"), after Phase by phase: the five fields with their values, a meaning for each value, ten example cases and rules of thumb (Backlog is not On hold; Health from Build on; Planning Status only for planning cycles). The values are the dictionary's; the page has no data of its own, so a value change in the dictionary needs the same change here (a test pins the five lists).
