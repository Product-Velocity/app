**The default labels Product Velocity writes to GitHub and Jira are `pm:` (Product Management), and no base label is sent by default (issue #468).** Defaults only: `pm:moscow/<value>`, `pm:rank/`, `pm:type/`, `pm:group/`, `pm:project/`, `pm:quarter/`, `pm:value/`, and the optional `pm:focus/` and `pm:tag/`; `pm:removed`, `pm:define`, and the Jira marker `pm:item/<hash>`. The base label (`product-velocity`) is no longer sent unless a project names one. A project that saved its own names keeps them: both Jira projects in production already stored `pm:` names with the base label off, and GitHub had no saved names. **Old labels are cleaned up, not left behind:** `pv:` labels and `product-velocity` are always treated as ours, so the next confirmed Sync removes them from an issue and adds the `pm:` ones; `pm:` is always ours too (a project that later moves to its own names has them cleaned). `pv:removed` and `pm:removed` record a confirmed close and are never taken off. The block word in the GitHub body (`pv`) is not a label and stays. Nothing changes in a tracker until a person confirms Sync.

**Jira Priority, Target start/end and field errors (issue #469).** (1) A newly linked Jira project gets the suggested priorities (highest = Must, then Should, Could, lowest = Won't) saved when none are saved yet, so Priority is sent from the first Sync; for an existing project the field configuration shows the suggestion pre-selected and one Save turns it on. (2) Jira Plans "Target start" is offered and ranked like Start date, "Target end" like the due date (both were already selectable as date fields). (3) When Jira refuses Priority, the due date or a custom field because it is not on the issue type's screen, the issue is sent again without that field and the result says which field and what to do; the summary, description, labels, project, type and parent are never dropped. **Not built, by decision:** Parent as Initiative Group (Parent is a hierarchy link to a real Jira issue; the group stays the `pm:group/` label), Team, Fix versions, Assignee, Reporter and time tracking.
