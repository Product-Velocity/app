**Roadmap Category is hidden; Business Value Type and Planned Quarter become labels; Focus Area also goes into a Jira text field (issue #324).**

- **Hide, not remove.** `HIDDEN_FIELDS` (packages/domain `registry.ts`) lists `roadmap_category`. It stays in the dictionary, the database, the CSV and the API (and in saved data), but is not shown: not a grid column, filter, group or sort, not in the item panel, bulk edit, default or saved views (`sanitizeView` drops it), nor in the Help columns table. Remove it from `HIDDEN_FIELDS` to bring it back. Its `pv:category/…` label and slots are retired: the next Sync removes a `pv:category/…` label from an issue, as it does any `pv:` label that no longer applies. The Leadership "investment mix" chart and its weekly-update text now use Business Value Type (Ashu, later the same day); the Leadership default view lists Business Value Type in place of Roadmap Category (`default-views.csv` and `.json`).

Ashu chose to send it as `pv:value/<type>`. It is a category, not an amount: Business Value (12m run-rate), Business Value Basis, confidence and every other commercial field stay never synced. `value_type` is removed from `NEVER_SYNCED` and added to both outbound allowlists; tests pin that the amount and basis never reach a payload.
