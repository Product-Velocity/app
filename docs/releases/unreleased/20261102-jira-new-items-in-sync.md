**Decide on new Jira issues when you sync (issue #67, fifth part).** For a project that uses Jira, "Sync" opens with "Sync with Jira: new issues first": the open issues of the linked Jira projects are read, then you pull in what belongs (read only or owned by Product Velocity) and ignore the rest, in the same list as for GitHub, with Jira keys. Each issue goes into the project linked to its own Jira project. Comparing and sending changes to Jira is not available yet; the dialog says so. No migration.
