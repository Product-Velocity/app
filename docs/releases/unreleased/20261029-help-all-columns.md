**Help lists every column.** The Columns tab of Help now has one row for each of the 169 columns, grouped as in the grid, with a filter box. Each row shows what the column is, how it relates to GitHub and to Jira (planned), and whether it is read-only or read/write. The table is built from the field dictionary, so a new column appears in it automatically. No migration.
