**Excel export "Roadmap with epics".** The Export menu (and the command palette) now has a second Excel file: each initiative on its own bold row with the issues of its linked Jira or GitHub issue beneath it as collapsible rows (type, key as a link, status, status group, assignee, last updated), followed by the columns of your view. It reads what is already held, writes nothing to Jira or GitHub, and works for the selected rows or all shown rows. No migration.
