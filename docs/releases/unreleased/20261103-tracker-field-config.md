**GitHub and Jira settings in two sections, and a field configuration.** Settings, Integrations, GitHub and Jira each have the same two tabs: "Connect and configure" (status, projects, repositories and boards, issues waiting for a decision, and the new Field configuration) and "Sync logs" (what the sync did, Check now, Run again, live updates, the connection test). Field configuration reads the tracker's fields, including custom ones, shows where each Product Velocity field goes by default (exactly what Sync does today), and lets an admin change it per project: switch the pv: labels, the milestone, the issue type and the Artifacts and Files sections off, point the Jira due date, start date, Theme and priorities at other Jira fields, and Reset. Commercial fields can never be mapped, and tracker-driven fields stay read-only. The Sync preview says what is left out and why. New migration tracker_field_config.
