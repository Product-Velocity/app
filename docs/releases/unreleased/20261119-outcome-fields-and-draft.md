**Outcome fields go live, and Claude can draft a metrics request.** Outcome Review Date, Realized KR Value and % Realized KR Value, which were waiting for a later phase, are now read-only values worked out from the 30, 60 and 90 day reviews (they replace the "Next Outcome Review" and "Latest Realised KR Value" columns from the earlier release). Claude has a new tool that drafts the message asking for the metrics: text only, nothing is sent, and you still press Request metrics in the app. The Help pages are updated.
