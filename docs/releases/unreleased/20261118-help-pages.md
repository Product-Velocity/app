**Help is now a set of pages that open in a new tab.** The Help icon opens `/help`, organised by six topics: goals and impact (objectives and key results), the lifecycle and decision gates, alignment, reporting, delivery platforms (GitHub and Jira) and AI co-workers (brainstorm, Discovery and PRD documents). Each topic page is short and points to a Reference section that holds the long tables: every column and how it syncs with GitHub and Jira, status and sync rules, the reasons on Needs attention, report definitions, AI use-cases, assistant setup and keyboard shortcuts.
