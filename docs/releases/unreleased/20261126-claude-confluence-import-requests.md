**Claude can ask for a Confluence page to be imported, or a document to be updated from its page.** Claude never reads a page in or changes a document by itself: it leaves a request. On the Spec tab you see a notice (“Claude asked for a Confluence page to be imported as a document”, with Review… and Dismiss) or a chip “Update requested by Claude” on the document. Nothing is read until you review the preview and confirm, and that clears the request. Only a page that is already a link on the initiative can be asked for.
