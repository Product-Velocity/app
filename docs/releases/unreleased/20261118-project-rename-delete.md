**Rename and delete a project.** Settings, Workspace, Projects (admins): rename a project, or delete it with everything in it. Deleting asks you to type the project name and says exactly what goes: the initiatives (live and in the Trash) are deleted through the Trash and purge process, with their documents, files, votes and history, then the project itself. Jira and GitHub are not changed. A deleted project cannot be restored. Migration `project_rename_delete`.
