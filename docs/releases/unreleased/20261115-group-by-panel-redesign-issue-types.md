**A redesigned Group by panel, and a choice of which issues to show.** The panel is wide like Columns: the two levels as cards, the most used fields as the same one-click pills as the Quick filters, category tabs over a grid of fields, and a footer that stays in reach (also with the tablet keyboard open). "Show issues" is now a card: tick the issue types to list (Epic, Story, Task, Bug and any other type found, with counts), pick a preset (Everything, Epics only, Without bugs) and switch on "Hide Done and Cancelled". The chip on an initiative says how many issues the choice hides. The choice is saved with the view (migration `20261115102159_issue_types_and_hide_done`).
