**Stealth mode for GitHub and Jira.** In the field configuration of a project you can now rename what Product Velocity writes to the tracker, so nothing has to say "pv" or "Product Velocity": the text of each label (`pv:moscow/` can become `moscow/`), one prefix box that fills them all, the base, removed and define labels, the hidden markers, and on GitHub the footer and link back to the app. Labels sent under the old names are taken off at the next Sync. Nothing changes until you save a name. Migration `stealth_label_names`.
