**Velocity report works on workspaces that only have build dates.** The time spent in Build now shows in "Where the time goes", in "Working or waiting" and in the bar of each initiative in the list (it showed 0.0 when an initiative had no later date). When too few initiatives can be measured for Total or a gate, the report now says which dates are missing and how many initiatives have them, and points to Build, which only needs Start Building. "In flight and already slower than usual" follows the measure you chose.
