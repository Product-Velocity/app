**The bell counts changes per project, across all your accounts.** The pill on the bell shows how many Phase, Status, Health, Build status and linked-issue changes others (and GitHub and Jira) made since you last cleared it. Open the bell to see each project with its account and a count per type, press Clear counts to reset everything to 0, or click a project to open its change log (the Changes report) and clear that project. Your own changes are not counted. Decision notifications stay in the same panel. Migration `20261118133107_change_watch.sql`.
