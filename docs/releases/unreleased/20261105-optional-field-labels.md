**Optional labels for Tags, Focus Area and Roadmap Category.** On Settings, Integrations, GitHub and Jira, Field configuration, each project can now switch on three more labels for Sync: one `pv:tag/<tag>` per tag (at most 10), `pv:focus/<value>` and `pv:category/<value>`. They are off by default, so nothing changes until you switch one on; the Sync preview shows the labels before anything is written. Migration optional_field_labels.
