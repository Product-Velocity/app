**Changes report: the Roadmap's action bar, Source and Source type, and accessibility and test fixes.** The Changes report now has the same action bar as the Roadmap grid: Filter (quick filters and custom rules), Columns (show, hide, reorder), Group by (two levels: initiative, change type, source, source type or day) and Search, with the chosen columns and grouping remembered in your browser. The Source column is now called Source type (UI, API, Claude MCP, GitHub webhook, import, system) and a new Source column in front of it says where the value came from: Product Velocity, Jira or GitHub. A Build Status or linked-issue status set by the tracker no longer reads as a person's change: it says "Sync run by" the person who refreshed it. Group rows and issue rows in the Roadmap grid are now proper cells of their row (an accessibility fault found in review). The browser tests now run every night in GitHub, and the ones that had gone stale were brought up to date. No migration.
