**The Sync button names the platform you are connected to.** It used to say "Sync with GitHub" even for a workspace that only uses Jira. It now says "Sync with Jira", "Sync with GitHub", or "Sync with GitHub and Jira" depending on what is connected and which platform the initiatives in scope (the selection, or all shown) belong to; the same for the button in the initiative panel. With nothing connected it stays disabled and says "Sync with GitHub or Jira".
