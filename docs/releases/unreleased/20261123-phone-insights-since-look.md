**Insights and a catch-up card on the phone.** The Insights tab now shows the key numbers (active initiatives, those needing attention, those waiting for a decision) and four charts: health, where the work is, build progress by project and planned quarters. Each chart has a one-line summary and a table view. Initiatives shows "N changes since Friday" with Review and Mark all seen; your own changes are left out, and what you have seen is remembered on that device.

On a phone the top bar is now a single compact row, the bottom bar has icons, and an initiative opens as a normal page instead of a panel laid over the list.
