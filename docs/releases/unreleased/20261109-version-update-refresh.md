**Update available prompt, Refresh button and What's new dialog.** Open browser tabs now check `/api/version` when you return to the tab, open the account menu or keep the page open, and show an "Update available · Refresh" button in the top bar and at the bottom of the account menu with a summary of what changed when a new version is deployed. A new "What's new" button next to the version number in the account menu opens the recent release notes from `docs/RELEASES.md`.
