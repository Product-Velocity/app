**Decide the final order, and say why (issue #397).** The vote informs; you decide. On the results page of a closed alignment session, start from the vote's order and change it: move an initiative up or down, or type the place it should take, and tick which ones to include. The review step shows, for each initiative, where it is now, where the vote suggested and where you put it, and asks for a short reason (up to 300 characters) wherever your order differs from the vote, including when you keep something in place that the vote would move. Reasons are kept with the change, shown on the results page under "Applied before" and in the item panel's Alignment tab ("The vote suggested #2. Decided #5 (was #9). Reason: ..."), and are seen by admins only and never sent to GitHub or Jira. The database checks the rule itself, so it cannot be skipped. Apply stays a plain admin action; Claude, the MCP server and service accounts still cannot apply or undo. New migration `20261110112748_alignment_rank_reasons.sql` (a new table; replaces the apply function from the previous release; nothing dropped).
