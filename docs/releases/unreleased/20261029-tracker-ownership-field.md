**New column: Tracker Ownership (issue #256).** A linked initiative now shows who owns it: **Product Velocity** (it sends the name, summary, description and hypothesis after a preview and a confirmation) or **Tracker (read only)** (it only follows the issue). It sits next to Synced With in the Delivery view, is blank when the initiative is not linked, and is read-only in the grid: change it with **Take ownership** / **Make read only** on the GitHub tab, or with the choice when you pull an issue in. The dictionary now has 170 fields. Help lists the new column and explains the choice. No migration (the value is derived).
