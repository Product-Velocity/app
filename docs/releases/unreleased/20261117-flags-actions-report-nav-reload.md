**Changes report uses the Flags and Actions columns; a page that fails to load reloads itself once.** The single Follow up column of the Changes report is now two columns, Flags and Actions, the same as in the main grid. When a page failed to load while moving between screens (for example right after a new release), Reports and the other screens now reload once by themselves, and only show "This page couldn't load" with Reload, Try again and Back if it fails again within a minute.
