**Changes report names the Jira user on Build Status changes that follow child tickets.** When Build Status moves because child issues or sub-tasks of the linked Jira issue moved (not the linked issue itself), the Jira user column now shows who moved them since the initiative's last tracker change: up to two names, latest first, and a count of the rest. The daily check now also reads the status history of those children. Read-only, no migration.
