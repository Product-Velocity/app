**Incoming has a Re-pull button for issues you already pulled in.** On the Pulled in tab, tick initiatives and press Re-pull: each issue is read again and the Description, Change Type (from a `type:` label) and Focus Area (from an `area:` label) that are still empty are filled. A field that already has a value is never replaced and nothing is written to GitHub. GitHub only for now; Jira follows with #365.
