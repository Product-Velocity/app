**One grid for the Jira epics of an initiative.** The list of Jira epics and the table below it are now one grid: add keys at the top, filter by type and status, select one, several or all rows, and Check, Copy links or Remove them from the toolbar or per row. Copy gives the Jira links only, one per line. The Depends On field (and the other initiative lists) has a Copy list button that gives "R-104 Name" lines to paste. Nothing changes in what is written to Jira.
