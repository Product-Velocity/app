**Shortcuts, a Help guide and text size.** The top-bar button that listed keyboard shortcuts is now called Shortcuts. A new Help button opens a short guide with three tabs: the columns and how each relates to GitHub and Jira (and whether it is read-only), how content flows from reading GitHub or Jira through creating initiatives and the lifecycle, and how to use Claude with prompts that work. A− and A+ buttons make the text smaller or larger; the choice is saved in your profile and used the next time you open the app. No migration.
