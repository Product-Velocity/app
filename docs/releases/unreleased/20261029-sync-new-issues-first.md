**Sync with GitHub starts with the issues that are new (issue #256, part 3).** When you press **Sync with GitHub** in the grid and GitHub has issues that are not initiatives yet, the window first shows them, with the same choices as the Incoming page: pull in (Read only, or Product Velocity owns it) or ignore, with undo. **Continue to sync** then goes on to the usual preview of what came in, what goes out and any conflict; the check of your initiatives already runs while you decide. With nothing new it goes straight to the preview. Nothing is written to GitHub in the new step. Keyboard focus now moves into the window when it opens. No migration.
