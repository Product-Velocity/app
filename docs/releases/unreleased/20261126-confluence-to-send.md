**Confluence updates show up in Sync.** When a document is kept in sync with a Confluence page and has a newer version than the page, the Sync dialog now lists it in step 2 under “Confluence pages to update”. Each one has its own preview (with the warning for commercial text) and its own Confirm; “Apply and send” still only sends to the tracker. A page that was changed in Confluence meanwhile is not overwritten from there.
