**`pv-weekly` is now a leadership report: all initiatives by default, or only the ones you name.** Run `pv-weekly` and it covers every initiative; add codes, a range or a view to focus (`pv-weekly R-1 to R-5`, `pv-weekly group:"Growth"`). It is written for leadership: the bottom line and what you need from people first, then what happened and why it matters, grouped by theme or objective instead of listed ticket by ticket, compared with last week, what is at risk and what would unblock it, and what comes next. Choose the format with `--format`: email, slides (PowerPoint), document (Word), Slack or chat; a presentation or document file is built when your assistant has a capability for it, otherwise you get slide-by-slide text, and nothing is ever sent. The `get_report` tool takes the initiatives to cover and returns a short context block per initiative (phase, status, health, dates, days in phase, objective) so the summary can explain, not only list. `pv-release-notes` can be scoped to named initiatives too. Help shows which skills cover all initiatives or the ones you name.
