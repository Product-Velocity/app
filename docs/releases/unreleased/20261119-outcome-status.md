**Outcome Status.** The Outcome Status column is now worked out from the outcome reviews instead of waiting for a later phase: Not yet due before the first review, then Exceeded, On target, Behind or Missed depending on how far the latest realised value has come from the key result's start to its target (On target from 80%; Missed only below 50% once the 90 day review is recorded). It sits in the Outcomes view next to Initiative Phase. The cut-offs are defaults, written down for you to confirm.
