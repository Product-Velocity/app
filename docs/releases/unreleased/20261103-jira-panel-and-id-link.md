**Jira initiatives show their ticket next to the Initiative ID and have a Jira tab.** An initiative linked to a Jira issue now shows the key (for example SCRUM-2) as a link next to its ID in the grid, as GitHub shows #142. In the initiative panel the tab, the header line and the Sync button say Jira instead of GitHub: the tab shows the issue, Jira's status and Build Status, who owns the initiative, and a Take ownership or Make read only button (writes nothing to Jira). An initiative with no Jira issue yet explains that Sync with Jira creates one after a preview.
