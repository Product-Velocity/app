**The Spec tab uses one row for documents, files and links.** Each entry has an icon or thumbnail, a name, one line of detail, a sharing chip ("Shared with GitHub" or "Only in Product Velocity", one click to change, for documents too) and a "⋯" menu (Open, Download, Copy link, Rename, Remove). One **Add** menu (Write a document, Upload files, Add a link) replaces the separate add controls; the search, the type filter and Add sit on one line; the whole tab is the drop zone. Files and links can be renamed; a link without a name shows its domain.
