**Help shows how each column is updated.** The Columns tab has a new "Updated by" column: you edit it, manual sync (Sync with GitHub), auto sync (the daily check), webhook (real time), calculated, or set by the system. Tracker columns such as Build Status, issue counts, pull requests and CI show all three tracker routes; texts go out only by manual sync after you confirm; commercial and decision columns can only be changed by you.
