**Files and links now live on the Spec tab.** Screenshots (files) and Artifacts (links) move from the Overview tab to the Spec tab, next to the documents. Attach files by choosing them, dragging them onto the tab or pasting an image; paste a web address to add a link. New files are shared with the GitHub issue or Jira description by default (private repositories only, as before); "Do not share" keeps one in Product Velocity only. Written documents are still never sent.
