# Pricing (draft) and pitch notes

## Original idea (Ashu)
By number of user accounts: ≤5 €29.99; ≤25 €59.99; ≤50 €99.99; ≤100 €149.99; ≤250 €249.99; more → call. Upsell coding-AI integrations and token packs.

## Concerns raised
1. Define "user": alignment voters (sales, customers) could be hundreds. Count only full members.
2. Per-account price falls from €6.00 (5 accounts) to €1.00 (250): very low for an enterprise-GitHub product; enterprise buyers may read it as unserious and it may not cover support/security reviews.
3. AI costs real money per use: include an allowance, sell packs beyond it.
4. Gate enterprise features (SAML, audit export, custom templates, GitLab) by tier.

## Working plan (confirmed by Ashu 2026-10-21; prices still to validate with buyers)
Team €18 / Business €36 per full member per month (minimums 5 / 10); Enterprise custom (100+). Viewers, commenters and alignment voters free. AI allowance per plan + token packs. Validate against 3–5 competitor price pages and buyer conversations before launch. Billing (Stripe) is built after the pilot (Phase 9) — track seats and AI usage from day one.

## Pitch (see prototype Pitch-1…8, Deep-1…7)
Story: decide → deliver → learn. Demo path (10 min): idea in Claude → item and spec → alignment → fit line → GitHub issues → agent PR → live progress → monthly review deck. Objections: security/audit/SSO (Phase 9), "GitHub only" (GitLab next), public repos (commercial fields never sync), AI governance (guardrails, Approver). Say "go-to-market ready". No "first/only" claims. Velocity numbers in the deck are examples.
