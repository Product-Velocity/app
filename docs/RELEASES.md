# Release log

The version is shown at the bottom of the account menu ("app v0.30.0 · build abc1234"). **A release is a pull request merged into `main`.** Do not edit this table or `version` in a feature PR: add a release fragment in `docs/releases/unreleased/` instead, and the release workflow gives it the next version when it is merged (issue #238, `docs/23-PARALLEL-WORK.md`). A test fails if `version` and the top row disagree. Numbering: `1.MINOR.PATCH` (it was `0.MINOR.PATCH` up to 0.140.0; Ashu moved it to 1.140.0 on 2026-11-11); a new feature or screen is `bump: minor`, a fix or a docs-only change is `bump: patch`. The build id is the first seven characters of the Git commit Vercel deployed.
