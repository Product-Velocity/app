# Release log

The version is shown at the bottom of the account menu ("app v0.20.1 · build abc1234"). **A release is a pull request merged into `main`.** Every PR that changes what the app does bumps `version` in `apps/web/package.json` and adds a row at the top of this table (a test fails if the two disagree). Numbering while the product is pre-launch: `0.MINOR.PATCH`; a new feature or screen bumps MINOR, a fix or a docs-only change bumps PATCH. The build id is the first seven characters of the Git commit Vercel deployed.
